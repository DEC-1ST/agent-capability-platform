# Security Policy

## Supported Versions

Only the latest release and the default branch are currently supported.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public issues.

Use GitHub's private vulnerability reporting for this repository.
Include a clear description, affected component, reproduction steps,
impact assessment, and any proposed mitigation.

Please do not include secrets, production credentials, private logs,
server addresses, or personal data in a report.
